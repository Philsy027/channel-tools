# Channel Tools

Channel Tools is a personal, single-user command-line application used by its
author to publish and manage videos on his own YouTube channels. It is not a
product, it is not offered to other people, and it has no users other than its
author.

## What it does

- Uploads finished video files to the author's own YouTube channels, with their
  title, description, tags and synthetic-media disclosure.
- Sets thumbnails and caption tracks on those videos.
- Changes the visibility of those videos between private, unlisted and public.
- Reads the author's own channel statistics — views, watch time, and thumbnail
  impressions — to inform editing decisions.

## Google account access

It uses the YouTube Data API and the YouTube Analytics and Reporting APIs
through Google OAuth 2.0. It only ever acts on channels the authenticating
account owns.

See [PRIVACY.md](PRIVACY.md) for exactly what is accessed and stored.
